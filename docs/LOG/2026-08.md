- **Spec**: §F.1 task (b) (chameleon coercion); `src-resolve` §3.17.6.2

- **The defect.** `symbols.simpleTypes` held a bare `*Element` with no owning
  producer, so an on-demand `buildSimpleType` triggered from a foreign or
  referring document resolved that type's unqualified `base=` under the
  **asking** producer. The asker's `unqualifiedRefNS`/`declares` are always
  false for a foreign declaring element, so a chameleon-included document's own
  unqualified `base=` took the absent namespace instead of §F.1's coerced
  target namespace — a false reject, and exactly the class #228 had already
  fixed one index over for `symbols.complexTypes`.
- **The grounding's load-bearing finding is that resolution authority does not
  travel with the request.** The oracle established that §F.1 coercion updates
  unqualified QName references (`xs:*/@base` included) in the DECLARING
  document, coercing to that document's own target namespace — a property of
  the document holding the attribute, not of whoever asks for the build.
  §4.2.3's `c-incl-incl`/`c-incl-ns-capture` explain why a foreign producer can
